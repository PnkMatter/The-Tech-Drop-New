# the tech drop.

> *Your signal in the noise.* A personalized, editorial-style experience for discovering what matters in technology.

**Client project** designed and built end to end as a freelance engagement.

## Stack

- **Next.js 16** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS v4** + **shadcn/ui** components
- **pnpm**

## Highlights

- Editorial layout focused on readability and content hierarchy
- Responsive, mobile-first design
- Component-driven UI built on shadcn/ui primitives

## Run locally

```bash
pnpm install
pnpm dev
```

Build for production:

```bash
pnpm build
pnpm start
```
